# Умный дисплей ЖК (Ujin)
Запуск: `pip install -r requirements.txt && python main.py`
- Панель УК: http://localhost:8000/
- Дисплей: http://localhost:8000/display/main_hall_01 (в Android WebView)
- Предпросмотр шаблона: из панели, кнопка «Предпросмотр» (рамка 9:16)
При смене схемы БД удалите `ujin_displays.db`.
